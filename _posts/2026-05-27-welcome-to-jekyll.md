This is your first post. Jekyll renders any Markdown file in the `_posts`
directory whose filename follows the `YYYY-MM-DD-title.md` pattern.

## Writing posts

Add front matter at the top of each file and write your content in Markdown
below it. Categories and tags are picked up automatically by the archive pages.

```ruby
def hello
  puts "Code blocks are syntax-highlighted in the dark skin."
end
```

Edit or delete this file in `_posts/` to make the site your own.
